What's New

Builds

Save named snapshots of your current build to switch between them later — stored locally in this browser, not synced anywhere.

Manage Owned Tracking

Owned progress is tracked separately per build by default. Link this build to another to share the same live progress, merge in progress from another build without disturbing it, or split off your own independent copy.

Export Build

Copy this text to share your build, or save it as a .txt file. Pasting it back in via Import restores everything — owned progress included, always landing in its own separate tracking on the receiving end, never overwriting theirs.

Import Build

Paste just the build code, a whole share link, or the full exported text (the code gets pulled out of any of those) — or load a .txt file exported earlier.

Reset Build

Clears every planned pick across every class you've used, not just your current 3 (picks for a class you've swapped away from are trimmed the same way, in the Other Classes tab). AAs marked as owned are kept by default, since those aren't just plans anymore — check the box below to clear everything, owned included.

Add Waypoint

Mark a point total worth returning to — it shows up as a labeled divider right where your training order crosses it. Give it a color to have that stretch of steps stand out at a glance.
